## Open or known-imperfect (as of 2026-10-25)

- `RB_COLORCONTROL` alpha function ignored (always GEQUAL); `k_8_8_8_8_GAMMA` treated as linear; **resolve exponent bias not applied**; k_24_8 from guest memory unsupported; 1D and 3D textures unsupported.
- Kill-vertex moves the vertex off screen: right for points, approximate for triangles with one killed vertex.
- Red outlines on edges and LOD swaps/grey balloons reported by the user were **not reproduced** after the param_gen fixes (likely stale-state class).
- The in-level dialog box sometimes shows red/green vertical stripes (seen in the third round; not seen later).
- "After the Toy Box re-places a figure the HUD shows the default name instead of the nickname" (figure logic, not rendering) [?].
- MSAA is not emulated; EDRAM aliasing is not emulated (not needed so far; Swap Force resolves one EDRAM range as `k_16_16_16_16_FLOAT` that nothing drew in that format: black on the host [?]).

- **Offscreen frames do not prove a window** (2026-10-30): `SKY_DUMP_FRAME` and `SKY_GPU_SNAPSHOT` read render targets or the offscreen output; the swap chain's path (Metal, a real window) is never read. `SKY_PRESENT_PROBE=<n>` logs what the present samples and reads that texture back, which proves the picture reaches the present; only a capture of the window (`screencapture -l <window id>`) proves the window.

## Lesson list (what to do first on the next game)

1. Build the ring mirror before any level work and diff shadow vs ring per draw (`SKY_D3D_CAPTURE` prints both).
2. Take per-shader state (param_gen enable + register) from the shader header; NGL registers from the ring; inherited state after command-buffer runs.
3. Find CPU readers of resolves early (write-protect the page).
4. Capture one level frame and write its pass list before fixing anything.
5. Every "stale" bug of this list was *"the shadow or the mirror held another draw's value"*: check for it before suspecting translation.
